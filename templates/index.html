Recommendation Architecture

How Our AI-Based Recommendation System Works

Unlike black-box commercial systems that require paid API subscriptions, our application implements an offline Content-Based Recommendation Engine written in pure Python. It creates a personalized academic learning pathway for each student through four deterministic scoring dimensions:

1. User Interest Profile Vector

Matches books directly against student registered topics (e.g. Programming, Artificial Intelligence, Cybersecurity).

2. Borrowing History & Activity

Analyzes books previously requested to identify reading preferences and domain depth.

3. Cross-Domain Curriculum Ontology

Maps related computer science branches (e.g., Programming → Data Structures → Web Development).

4. Explainable AI Rationale

Every recommendation is paired with an explicit, human-readable reason so the student understands why it was chosen.

Algorithm Scoring Formula
Relevance Score =
(Category_Match × 12) +
(History_Category_Match × 10) +
(Cross_Domain_Weight × 5) +
(Keyword_Tokens × 3) +
(Availability_Bonus × 2)
