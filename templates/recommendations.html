College Project Viva Notes: AI Recommendation System

This module uses a deterministic Content-Based Filtering algorithm. The algorithm computes a weighted relevance vector:

  • Interest Matching (+12 pts): Computes overlap between student's registered topics and the target book's domain category.
  • Borrowing History Affinity (+10 pts): Enhances scoring for subjects where the student has actively borrowed titles previously.
  • Cross-Disciplinary Ontology (+5 pts): Connects inter-related branches (e.g. Programming is paired with Algorithms and Web Development).
  • Explainability: Eliminates the "black box" issue by dynamically synthesizing explicit justification reasons for each recommendation.
